### 🎹 [`omid`](https://github.com/FaezBarghasa/omid) — Object-MIDI · Unified Audio & Hardware Protocol

> **A `#![no_std]` Rust library for next-generation MIDI, digital audio, and hardware control events.**
> Built to spec **OMID 2.0.0 (Global Unified Audio, Control & Driver Standard).**

A ground-up hardware-level event system designed for zero-copy DMA pipelines, USB/PCIe high-speed endpoints, and IoT wireless interfaces — with MIDI 2.0 translation built in.

| Feature | Engineering Detail |
|---------|-------------------|
| **8-byte fixed packets** | DMA-aligned, zero-copy, cache-line friendly layout with zero serialization overhead |
| **High-res ADC Engine** | 12-bit faders (`0..=4095`), 16-bit keys (`0..=65535`), automatic `RAW_DATA` flags |
| **Haptic Force Feedback** | Bi-directional EM profiles: Hammer Strike, Spring Tension, Kinetic Dampening |
| **UACT Framing** | Synchronized PCM + control packed into clock-locked DMA frames (up to 192kHz) |
| **Lock-free SPMC Dispatcher** | Core affinity-pinned RT DSP threads with configurable zero-latency callback API |
| **RTT Auditing** | Monotonic hardware timer hooks for host→device sub-microsecond round-trip measurement |
| **MIDI 1.0 / 2.0 Bridge** | Packs Omid events into 128-bit MIDI 2.0 Universal MIDI Packets (UMP) |
| **FFI Bindings** | Clean C-ABI bindings (`libomid.so` / `omid.dll`) for C++, Go, Python, TypeScript, Dart, C#, and Java/Kotlin |
