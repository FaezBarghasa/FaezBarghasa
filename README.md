### 🎹 [`omid`](https://github.com/FaezBarghasa/omid) — Object-MIDI · Unified Audio & Hardware Protocol

> **A `no_std` Rust library for next-generation MIDI, digital audio, and hardware control events.**
> Built to spec **OMID 2.0.0 (Global Unified Audio, Control & Driver Standard).**

This is not a MIDI wrapper. It is a ground-up hardware-level event system designed for zero-copy DMA pipelines, USB/PCIe high-speed endpoints, and IoT wireless interfaces — with the full MIDI 2.0 ecosystem as a translation target.

**Core architecture highlights:**

| Feature | Detail |
|---------|--------|
| **8-byte fixed packets** | DMA-aligned, zero-copy, cache-line friendly |
| **High-res ADC** | 12-bit faders (`0..=4095`), 16-bit keys (`0..=65535`), auto `RAW_DATA` flag |
| **Haptic Force Feedback** | Bi-directional EM profiles: Hammer Strike, Spring Tension, Kinetic Dampening |
| **UACT framing** | Synchronized PCM + control packed into single clock-locked DMA frames (up to 192kHz) |
| **Lock-free SPMC dispatcher** | Affinity-pinned RT DSP threads, configurable callback API |
| **RTT auditing** | Monotonic timer hooks for host→device round-trip measurement |
| **MIDI 1.0 / 2.0 bridge** | Note On/Off, CC, Pitch Bend; packs Omid into 128-bit MIDI 2.0 Sysex8 UMP |
| **SPSC queue** | Cache-line aligned, power-of-two masking, batch `push_many`/`pop_many` |
| **Platform drivers** | `WifiDriver` (TCP/UDP), `LinuxDriver` (`/dev/omid0` usbfs), `BleDriver` (GATT), WebUSB |

**FFI — 8 language bindings** via `libomid.so` / `omid.dll`:
